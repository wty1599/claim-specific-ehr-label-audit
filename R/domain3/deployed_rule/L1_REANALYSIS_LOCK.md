# L1 D3 external reanalysis specification

Date written: 2026-09-25, before any new eICU L1 assignment or outcome analysis. This is a post hoc reanalysis authorized after the original L2 surrogate results and the L0/L1/L2 development decomposition were known. It is not a preregistration. Original data, K2 labels, L2 model outputs, manuscript, supplement, and figures are read-only. New patient-level outputs stay in this local `private_local` directory and are never uploaded publicly.

## Question and allowed change

Can the original K2 centroids and MICE-1 coordinate parameters, combined with the previously used post-winsor observed-value median for each of 33 features, be deployed consistently in both MIMIC-IV and eICU? The only scientific rule change from L0 is inductive median imputation in place of cohort-wide MICE completion. L1 retains original winsor limits, original center/SD, feature order, and recovered fixed-label centroids. L2 is the archived reconstructed rule and is the historical comparator. No reclustering or rerunning MICE is allowed.

Use the recovered aggregate object `../outputs/original_parameters_aggregate_v1.rds` with SHA-256 `70CEAD3058658339D3AE00753F7B21045F0BBCCB74B8E9267FC2F5B906931C99`. The saved matrix, locked labels, MICE completion, raw MIMIC source tables, old L2 object, and original eICU input must match the fingerprints recorded in the previous-stage recovery report and the archived D3 configuration. All joins are by `stay_id` (MIMIC) or `patientunitstayid` (eICU), never row count alone. No eICU outcomes may be read in the assignment stage.

## Assignment and descriptive comparisons

- Apply L1 to all 20,049 MIMIC records and the same 17,465 eICU stays. Report L1/L2 differences by external ID, C1 counts and pooled prevalence in both cohorts, and source locked-label C1 prevalence separately.
- Retain the original eICU feature-coverage and absolute-lymphocyte provenance checks, 16,212 patient and 199 hospital denominators. Use the existing archived eICU L2 labels as comparator, not a re-run of the historical analysis.
- Across 199 hospitals, report unweighted median, 25th/75th percentiles, range, and number whose raw hospital C1 prevalence differs by more than 0.10 absolute from the corresponding pooled MIMIC L1 prevalence. This hospital count is descriptive; the original prespecified 0.10 gate applied to the pooled cross-cohort difference, not each hospital.
- Missingness bands are fixed from the old D3 script: 0, 1-2, 3-5, and 6+ missing of 33 source features, counting nonfinite raw inputs before median filling. In MIMIC, report total L0-to-L1 flip rate and directional counts/rates (locked C1 to L1 C2, locked C2 to L1 C1) by band, using total-band and source-label denominators explicitly. In eICU, report band size, L1 and L2 C1 prevalence, and L1-L2 directional discordance. These are descriptive checks, not new transport gates.

## Outcome models and frozen comparators

- Train exactly two new label-dependent logistic models in MIMIC: `glm(y ~ age + sex + sofa_score + aki_stage_0_24h + factor(L1_K2), family=binomial)` for (1) `hospital_mortality` and (2) `make30`. Use the original 20,049-row model cohort, same sex parsing, original complete-case restrictions, factor levels 1/2, and no interactions or tuning.
- Apply the models to the identical original eICU complete-Base samples: `hosp_mortality` for mortality; `make_hosp` (death or last-ICU-creatinine criterion) for the kidney composite. The kidney endpoints are non-equivalent and all cross-database calibration there is descriptive. Keep the original 24-hour AKI-stage covariate, outcome coding, and no extra missingness exclusions. Check denominators against the archived D3 table before interpreting results.
- Base, Raw-EN (`feat_pen`), and Raw-RF (`feat_rf`) do not use K2. Do not refit or recompute them. Read their archived aggregate performance and restricted patient-level predictions only where needed for a paired contrast. First verify archived patient-level predictions reproduce archived AUC and calibration point estimates for the old L2 model and Raw-EN within numerical tolerance. Failure stops rather than silently substituting a model.
- For each new Base+L1 K2 model, report external AUC; patient-cluster percentile-bootstrap 95% CI with 1,000 replicates; calibration slope and intercept; patient-cluster bootstrap 95% CI with 1,000 replicates; Brier score; and first-recorded-stay descriptive sensitivity as in the old D3 script. The source modeling formula and external-complete-case selection are unchanged. Confidence intervals are conditional on fitted model predictions, with no prognostic-model refit in the bootstrap.
- Calibration bootstrap uses the original `04b` seed schedule: sorted outcome order `make`, `mortality`; seed `20260728 + 9100 + outcome_index`, resampling `uniquepid` with replacement and refitting only calibration regressions. AUC uses the same patient-cluster percentile method and 1,000 replicates, with separate fixed seeds `20260728 + 9000 + outcome_index` to make the new restricted run reproducible; it is not claimed byte-identical to the old monolithic script's RNG stream.
- For Raw-EN minus Base+L1 K2, use the original paired patient-cluster AUC-difference function and 1,000 replicates. Preserve the old contrast seeds for `feat_pen - base_gen`: `20260728 + 5000 + 2` for mortality, `20260728 + 5000 + 6` for make. Validate old Raw-EN predictions and outcomes by ID. Other Raw-EN performance values are cited from the archive unchanged.
- A ten-fold stratified MIMIC internal-CV check for the two Base+K2 models may be run only with the same original fold-generation and GLM procedure. Use fixed independent fold seeds `20260728 + 9200 + outcome_index`, the same folds for L1 and an L2 comparison, so the within-reanalysis comparison is paired. These folds are not represented as identical to the original monolithic script's stateful RNG folds. No Raw model is refitted.

## Results, interpretation, and pause rule

Calculate without changing the prespecified pooled prevalence-drift threshold (absolute difference >0.10), calibration slope interval 0.80-1.20, or absolute calibration-intercept threshold 0.20. Distinguish point-estimate gate alert from bootstrap uncertainty. A 95% slope CI that excludes 1 supports calibration deviation; whether it crosses 0.80 describes uncertainty about the gate's severity. Calibration cannot establish external semantic label identity, which remains without an independent eICU reference.

Report old L2 and new L1 side by side in the supplement; the main text uses L1 only after numerical and figure consistency review. Stop before editing manuscripts if a pooled gate verdict changes; if the mortality slope interval no longer excludes 1; if external AUC moves by at least 0.02; or if the hospital heterogeneity pattern changes materially (a shift of at least 20 in the number of hospitals beyond 10 percentage points, or at least 0.05 in the median prevalence). Also stop for any change in endpoint/denominator or failure to reproduce archived controls. These pause criteria govern review of a post hoc update; they are not new scientific acceptance thresholds.

The old Figure 4A held-out L2 fidelity includes refitted split-specific centroids. Fixed full-cohort original centroids are present in L1, so a split-recipe perturbation cannot be called independent held-out validation. Figure 4A may preserve the forest-plot visual grammar but must change row descriptions or retain L2 as historical comparison with clear labeling. No CI or row is fabricated by relabeling the old result. Figure 4B and affected outcome panels are regenerated only from locked aggregate outputs. Figure changes precede manuscript edits; any substantive design change is recorded.

No patient-level data, external labels, predictions, or hospital identifiers enter a public package. All numerical results, figures, supplementary comparisons, and prose are generated only after this lock file has been hashed. Source files and old releases are never overwritten.
